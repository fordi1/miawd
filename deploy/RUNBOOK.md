# راهنمای عملیاتی (Runbook) — موعد

برای تو، صاحب پلتفرم. کوتاه و عملی. همه‌ی دستورها روی **سرور** اجرا می‌شن (داخل پوشه‌ی پروژه، مثلاً `/opt/mawid`).

## ۱. چی کجاست

| | |
|---|---|
| پنل ادمین (تو) | `http(s)://آدرس-سرور/admin` |
| پنل صاحب محل | `http(s)://آدرس-سرور/app` |
| مستندات API (برای یکپارچه‌ساز) | `/docs` (مرجع)، `/docs/guide/en`، `/docs/guide/ar`، `/docs/postman.json` |
| Endpoint ثابت API | `http(s)://آدرس-سرور/v1` |
| سلامت سرور | `/health` |

## ۲. اولین بار: ساخت ادمین

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml exec app node dist/db/createAdmin.js ADMIN_USERNAME
```

رمز به‌صورت تصادفی ساخته و **فقط یک بار** نشون داده می‌شه. جایی امن ذخیره‌ش کن.
فراموشی رمز ادمین:

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml exec app node dist/db/createAdmin.js ADMIN_USERNAME --reset
```

## ۳. اضافه کردن یک کسب‌وکار جدید (مثلاً مؤسسة النور)

1. وارد `/admin` شو ← «المحلات» ← «إضافة محل».
2. اسم محل، یک اسم کاربری (انگلیسی کوچک) و یک رمز **مؤقت** بده. اگه محل بره پیش زبون (تعمیرکار)، «بروح لعند الزبون» رو روشن کن. اگه فقط برای تست/دمو هست «محل تجريبي» رو بزن (با ۳ فنی و ۸ منطقه‌ی عمان پر می‌شه).
3. بعد از ساخت، **کلید API یک بار نشون داده می‌شه**: کپی کن و همراه رابط (`/v1`) برای یکپارچه‌ساز بفرست. اگه گم شد: صفحه‌ی محل ← «مفتاح جديد» (کلید قبلی همون لحظه از کار می‌افته).
4. اسم کاربری و رمز مؤقت رو به صاحب محل بده. اولین ورود مجبوره رمز جدید بذاره.
5. اگه یکپارچه‌ساز بخواد وقتی صاحب محل نوبتی رو عوض می‌کنه خبردار بشه: همون صفحه ← «Webhook» ← آدرس `https://…` اون رو بذار؛ «السر» رو به اون بده تا امضا رو چک کنه.

## ۴. کارهای روزمره

| می‌خوای… | کجا |
|---|---|
| ببینی چند محل و چند رزرو (در هر ماه) | `/admin` ← الرئيسية (شمارنده‌ها، رزروهای تست حساب نمی‌شن) |
| تقویم یک محل رو ببینی و تغییر بدی | صفحه‌ی محل ← «فتح التقويم» (هر تغییر به اسم «إدارة المنصة» ثبت می‌شه) |
| رمز صاحب محل رو عوض کنی | صفحه‌ی محل ← «كلمة سر مؤقتة جديدة» (از همه‌ی دستگاه‌ها خارجش می‌کنه) |
| محلی رو موقتاً قطع کنی | «إيقاف المحل» (کلید و ورودش بسته می‌شه، داده‌ها می‌مونن) |
| محل تستی رو تمیز کنی | «إعادة تعيين البيانات التجريبية» |

## ۵. پشتیبان‌گیری (Backup)

سرویس `backup` هر ساعت از دیتابیس دامپ می‌گیره: ساعتی‌ها ۲ روز و روزانه‌ها ۱۴ روز نگه داشته می‌شن (داخل ولوم `backups`).
**این‌ها روی همون سرور هستن**؛ برای امنیت واقعی باید بیرون از سرور هم کپی بشن (مثلاً به کامپیوتر خودت یا یک Bucket):

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml cp backup:/backups ./backups-copy
```

بازگردانی (روی دیتابیس **خالی یا جدید**؛ این دستور داده‌ی فعلی رو پاک می‌کنه، اول مطمئن شو):

```bash
gunzip -c backups-copy/daily-YYYY-MM-DD.sql.gz | docker compose --env-file .env.production -f docker-compose.prod.yml exec -T db psql -U mawid -d mawid
```

## ۶. به‌روزرسانی برنامه

```bash
git pull   # یا فایل‌های جدید رو جایگزین کن
docker compose --env-file .env.production -f docker-compose.prod.yml up -d --build
```

مهاجرت دیتابیس خودکار اول هر شروع اجرا می‌شه. بعدش تست کامل:

```bash
BASE_URL=https://آدرس ADMIN_USER=... ADMIN_PASSWORD=... node deploy/smoke.mjs
```

## ۷. HTTPS (خیلی مهم)

بدون دامنه فقط HTTP ممکنه؛ یعنی رمزها و **کلیدهای API روی اینترنت بدون رمزگذاری** می‌رن. برای جدی شدن:

1. یک دامنه یا زیردامنه بگیر و رکورد `A` اون رو به IP سرور بده.
2. در `.env.production`: `SITE_ADDRESS=api.example.com`، `PUBLIC_URL=https://api.example.com`، `COOKIE_SECURE=true`.
3. `docker compose --env-file .env.production -f docker-compose.prod.yml up -d` ← Caddy خودش گواهی رایگان می‌گیره و تمدید می‌کنه (پورت‌های 80 و 443 باید باز باشن).

## ۸. مشکل پیدا کردن

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml ps          # همه‌ی سرویس‌ها باید Up/healthy باشن
docker compose --env-file .env.production -f docker-compose.prod.yml logs app --tail 100
```

هر خطای API یک `request_id` داره (مثل `req_0f27…`). همون رو در لاگ جستجو کن.

## ۹. امنیت

- فایل `.env.production` (رمز دیتابیس، pepper کلیدها، سر توکن) فقط روی سرور باشه و جایی کپی نشه. اگه `API_KEY_PEPPER` عوض بشه **همه‌ی کلیدهای API باطل می‌شن**.
- دسترسی SSH رو با **کلید** کن (نه رمز root) و ورود رمزی رو ببند.
- رمز SSH یا هر رمز دیگه‌ای که در فایل یا چت گذاشتی رو بعد از تحویل عوض کن.
